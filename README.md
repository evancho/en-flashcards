# 英文詞卡

離線可用的英文單字卡。用手機瀏覽器打開、加入主畫面，之後沒有網路也能複習。

每個人都用同一個網址。單字存在各自的裝置裡，不會混在一起，也不會上傳。

公開網址：<https://evancho.github.io/en-flashcards/>

## 用 iPhone 裝到主畫面

請用 **Safari**。iPhone 上的 Chrome「加入主畫面」常常只是書籤，離線不一定可用。

1. 連上網路，用 Safari 打開 <https://evancho.github.io/en-flashcards/>
2. 點下方的分享按鈕（方框加向上箭頭）
3. 往下找，點 **加入主畫面**
4. 名稱可維持「詞卡」，點右上角 **加入**
5. 回到主畫面，點「詞卡」圖示。**這一次仍要有網路**，等單字卡畫面出現
6. 之後從這個圖示打開，不要只靠 Safari 分頁

主畫面圖示和 Safari 分頁有時各存一份單字。裝好之後，請一直用主畫面圖示新增、複習。

## 離線

服務工作線程（service worker）會在第一次成功打開時，把網頁檔案存到手機。單字另外存在瀏覽器的 localStorage。

確認可以離線：

1. 依上面的步驟，從主畫面圖示連網打開過一次
2. 打開飛航模式（或關掉 Wi‑Fi 與行動數據）
3. 從主畫面圖示再打開
4. 應看到詞卡畫面，可以翻卡、按「不會 / 有點生 / 會了 / 很熟」、新增單字
5. 把詞卡從多工畫面關掉，再從圖示打開，剛新增的單字還在

「備份」頁若出現「網頁已存進這台裝置」，表示檔案已經留下。

若很久沒打開，iPhone 有時會清掉網頁檔案。單字通常還在，但畫面若是空白，就再連上網路開一次圖示。清除 Safari 的「網站資料」會連單字一起刪掉，換機前請先匯出。

## 隱私

- 單字只寫在這台裝置的 localStorage（鍵名 `en-flashcards.v1`）
- 沒有帳號，沒有雲端同步
- 伺服器不接收卡片內容。線上時瀏覽器只會再抓這個網站的網頁檔，用來更新離線副本
- 換手機：在舊裝置「備份」匯出 JSON，到新裝置匯入

## 怎麼用

底部四個按鈕：

- **複習**：看英文，輕點卡片看背面，再評分
- **新增**：正面英文，背面中文或備註
- **詞庫**：搜尋、編輯、刪除。改文字不會重設複習進度
- **備份**：匯出、複製、匯入 JSON，或清除這台裝置的全部單字。也可以按「載入科技英文 100 詞」：新單字會加進來，已有的單字只補上缺少的例句，複習進度留著

右上角是目前待複習張數。

四個按鈕會把下一張排到不同時間（按鈕上會寫出這次的間隔）：

| 按鈕 | 大約會發生的事 |
| --- | --- |
| 不會 | 約 1 分鐘後再練。若這輪還有別張，會插回後面 |
| 有點生 | 還在學的先等 10 分鐘；已經會的只把間隔加一點 |
| 會了 | 學習中先 10 分鐘，再來隔 1 天，之後依熟悉程度拉長 |
| 很熟 | 直接拉到數天以後 |

間隔最長約一年。這是簡單的間隔重複，方便每天記單字。

空的詞庫可以按「載入科技英文 100 詞」，或「加幾張範例」先試五張。詞庫檔在這個網站上；斷線時若還沒載入過，畫面會請你連上網路打開一次。

翻開卡片後可以看英文例句。「發音」朗讀單字，「朗讀例句」朗讀那一句。聲音用這台裝置的英文語音，不會上傳。iPhone 請用 Safari 打開更新後的網頁，再從主畫面圖示進來，並點一下才會出聲。

主畫面若還是舊畫面，請連上網路從圖示再打開一次。打開「備份」，若看到「版本 v2 · 含例句朗讀」，這個圖示已經換到含例句朗讀的版本。單字仍在原來的 localStorage，不會因為版本字樣而清掉。

匯出的 JSON 若有 `example`（英文例句）和 `exampleZh`（例句中文），匯入時會保留。兩者都可以空白。

## 備份格式

```json
{
  "version": 1,
  "exportedAt": "2026-09-25T00:00:00.000Z",
  "app": "en-flashcards",
  "cards": [
    {
      "id": "卡片 id",
      "front": "apple",
      "back": "蘋果",
      "due": 0,
      "interval": 0,
      "ease": 2.5,
      "reps": 0,
      "lapses": 0,
      "step": 0,
      "createdAt": 0,
      "updatedAt": 0
    }
  ]
}
```

`interval` 是天數。`due` 是下次出現的時間（毫秒）。匯入可以合併（相同 id 以檔案為準），或取代這台裝置上的全部。

## 啟用 GitHub Pages

網站檔案在 `main` 分支根目錄（含 `.nojekyll`，避免 Jekyll 漏掉檔案）。若 <https://evancho.github.io/en-flashcards/> 還打不開，需要在 GitHub 按一次設定：

1. 打開 <https://github.com/evancho/en-flashcards/settings/pages>
2. 在 **Build and deployment** 裡，**Source** 選 **Deploy from a branch**
3. **Branch** 選 `main`，資料夾選 **/ (root)**
4. 按 **Save**
5. 等一兩分鐘，打開 <https://evancho.github.io/en-flashcards/>

儲存庫需維持 Public。這個動作要有儲存庫設定權限，程式本身無法代按。

## 本機預覽

在專案目錄執行：

```bash
python3 -m http.server 8080
```

用瀏覽器打開 <http://localhost:8080>。請用這個網址，不要直接點開 `index.html` 檔案，否則 service worker 不會運作。

排程邏輯測試：

```bash
npm test
```
